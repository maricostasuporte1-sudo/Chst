# Security policy

Creator Life 3D is an educational prototype, not a security-critical service.

**Supported version:** the latest code on `main` (best-effort maintenance).

Please do not post active credentials, personal information or exploitable secrets in public issues. For a potentially sensitive report, open a minimal issue without exploit details and ask the maintainer for a private reporting channel. The maintainer may configure GitHub private vulnerability reporting in the repository settings.

The game uses local `user://` save files; it does not require accounts or a server. Android debug APKs generated by GitHub Actions are for testing only and must not be represented as production-signed applications.
