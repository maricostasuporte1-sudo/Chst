# Contributing to Creator Life 3D

Thank you for helping improve this Godot learning project.

## Before opening a pull request

1. Create an issue or describe the bug or feature in your PR.
2. Keep changes focused on **Creator Life 3D**. Do not reintroduce Agendivo, VERTEX or unrelated private source code.
3. Use Godot **4.7.2 stable** and keep the prototype usable on low-end Android devices.
4. Run `godot --headless --path . --editor --quit` and `godot --headless --path . --script res://tests/smoke_test.gd`.
5. Describe how you tested the change, including device/OS and screenshots for UI changes.
6. Do not commit signing keys, passwords, user data, proprietary assets or large generated binaries.

## Pull requests

- Explain the motivation and summarize behavior changes.
- Include tests or a reproducible manual test plan for behavior changes.
- Keep backward compatibility with existing local saves where feasible.
- Respect third-party licenses and attribute reused content.

By contributing, you agree that your contributions may be distributed under this repository's MIT license and affirm you have the necessary rights to submit them.

## Bug reports

Include your Godot version, steps to reproduce, expected result, actual result, and (if available) a log with personal information removed.
